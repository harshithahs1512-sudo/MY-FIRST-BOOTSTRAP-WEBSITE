# MY-FIRST-BOOTSTRAP-WEBSITE
A simple website built using Bootstrap to explore its buttons, grid system,colour utilities,images and profile cards.A small project to practise Bootstrap components and understand how they make web development easier
<br>
#My First Bootstrap Website 

This is one of my beginner projects created while learning Bootstrap. I experimented with different Bootstrap components and utilities to understand how they work in a webpage.

### What I Used
- HTML
- Bootstrap 5

### Features
- Welcome heading with Bootstrap styling
- Bootstrap danger button
- Three-column layout using the Bootstrap grid system
- Different background colours for columns
- Image displayed using a Bootstrap card
- Profile card with name, designation and a button

### What I Learned
- How to use Bootstrap classes
- Working with rows and columns
- Using Bootstrap buttons and colours
- Creating cards with images and text
- Understanding how Bootstrap makes styling easier

### Preview
A simple Bootstrap practice website featuring colourful columns and a personal profile card.

This project is part of my web development learning journey. I'm exploring new concepts, practising them through small projects and improving my skills step by step
